# Vendeze design review - version 20

The complete website now follows the requested Partiful-inspired direction with Vendeze burgundy as the primary color. Review [every screen on desktop and phone](http://127.0.0.1:8005/design-review/whole-site/) or [open the application](http://127.0.0.1:8005/vendeze-connected/?preview=1#/).

The design includes the customer journey, sign-in and sign-up, profiles, vendor workspace, admin, marketing, developer tools, and recovery screens. Typography, navigation, service cards, forms, checkout summaries, states, and footers share one system.

For a walkthrough, search for a vendor, plan an event, select a package, send a message, add a hold, and preview a booking. Use the demo account selector on sign-in to explore the vendor, admin, and developer roles. The preview uses sample data in separate browser storage.

The same navbar now appears on every route, including sign-in and staff pages. Hover a main button to expand the shell in width and height; detailed links appear beside a photo, title, and description. Phone taps and keyboard navigation are supported.

Validation passed 267 site-wide journey/layout checks and 42 accessibility scans. The additional 141 navbar checks and nine accessibility scans cover hover, touch, keyboard access, role links, scroll behavior, expanded panels, and offline loading. Reports and screenshots are linked from [the handoff](UI_UX_HANDOFF.md).

The current review focuses on design and browser sample interactions. Live backend integration and real payments are outside this review. Earlier version 15-18 packages document previous designs.
